# 第二列紧凑界面

按本轮反馈，第二列统一采用微软雅黑（Microsoft YaHei），10pt 常规字重；搜索输入、模式选择、筛选、范围和结果列表使用同一字体体系。

顶部控件统一从 38 缩至 28 个逻辑像素高，搜索／发送按钮为 28 × 28，模式选择框宽 56。缩小内边距、行间距和圆角，保留浅色按钮底色和清晰的搜索主按钮。

按钮统一命名为“范围”。下拉菜单提供“电脑文件、资料库、两者”和“管理搜索范围”；悬停提示当前选择。电脑文件对应已选择并建立目录的位置，资料库对应已入库正文。空白页提示及筛选内的名称同步更新。

验证：379 项现有回归检查；100%、125%、150%、200% 四档缩放，浅／深色、普通／窄窗口、紧凑／舒适布局、探索／智答共 32 组布局检查。核对同高、对齐、文字完整和控件不越界，并记录实际解析到的字体。EXE 的实际代码归档及原生窗口另做核验。
