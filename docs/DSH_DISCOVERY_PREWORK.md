# 给 dsh：镜仔内置全盘发现模块前期任务

请在 `.` 工作。先阅读 `docs/NATIVE_DISCOVERY_PLAN.md`。本任务是下一轮接入前的底层准备，不是修改正式界面或发布新版本。

## 已确定要求

1. 不依赖 Everything 本体、SDK、ES 或其服务，也不依赖 Windows Search 索引。
2. 内置模块自行发现磁盘与目录，文件保留原位置，不要求复制入库。
3. 文件目录、正文理解和画面理解分层；此次先做文件目录与增量同步。
4. 后续界面名称为“探索／智答”。已有界面仍在使用，不能被本次前期任务覆盖。
5. 复用 Python 标准库 sqlite3／ctypes 和工程现有依赖。新增依赖如确有必要，先写明用途、许可证、体积、分发方式与替代方案，避免直接扩大生产依赖。

## 修改范围

允许新增／修改：

- `search_app/discovery/`：独立、无 GUI 的模块。
- `search_app/tests/test_discovery_*.py`：隔离测试。
- `tools/discovery_probe.py`、`tools/discovery_benchmark.py`、`tools/discovery_demo.py`。
- `docs/discovery_prework/`：设计、能力说明、实测报告、交接清单。
- 运行输出仅写 `.tmp/discovery-prework/`，或本任务新建的系统临时目录。

不要修改现有 Qt／Tk 界面、启动入口、打包脚本、正式 EXE、快捷方式、配置、原有 index.db 和用户资料。不覆盖其他线程的未提交内容；开始时记录工作区现状。不要用 git add . 收集整个工作区，也不要替用户提交或发布。

不安装服务／驱动，不修改 USN 日志，不自动提权，不改磁盘格式；不下载模型，不上传文件。前期实际创建、重命名和删除只能作用于本任务生成的临时样本。全盘内容解析、多模态推理不属于此次任务。

## P0：盘点与接口

- 阅读现有 backend.Store.scan、watcher.FileWatcher、indexer/parsers/searcher 和 Jobs。说明可复用点、不能直接用于全盘目录的原因。
- 形成 catalog.db 结构、接口类型与 JSON 示例，以 NATIVE_DISCOVERY_PLAN.md 的最小契约为准。
- 目录数据库与旧 index.db 独立。首次运行无写入旧配置／索引的副作用；模块 import 不启动扫描、监听或 GUI。
- 目录发现与内容分析使用不同排除规则。默认忽略项及覆盖缺口必须可解释。

## P1：先交付可运行的通用原型

- 使用流式 scandir 发现文件／目录，分批写 SQLite；不要先将整盘路径收集到一个列表。
- 元数据发现不打开每个文件的内容，不做全文件哈希、不调用文档解析器或 OCR。
- 支持多个来源、取消、进度、重启恢复、普通用户权限、错误隔离；失败项可追踪。
- 实现名称／路径查询、扩展名与来源筛选、排序及分页。候选必须按需读取，不能把整个数据库载入内存后再筛选。
- 中文、空格、引号、通配字符字面值、长路径、路径边界均需处理；不要把筛选根路径 `D:\资料` 错误匹配到 `D:\资料备份`。
- 重解析点／链接不形成递归循环；同一对象的多条硬链接路径不能静默丢失。
- 新增、更名、修改、删除可通过可重放事件更新。更名和内容变化分别记录。
- 实际监听可复用现有 watchdog 依赖或封装系统通知，但不要调用旧 watcher 的正文写库流程。监听失效／溢出后必须能安排补扫。

## P2：原生 NTFS 通道前期

- 提供卷列表和能力探测，输出文件系统、卷标识、权限状态、当前 provider 与回退原因。
- 封装只读的 FSCTL_QUERY_USN_JOURNAL、FSCTL_ENUM_USN_DATA、FSCTL_READ_USN_JOURNAL 所需结构和记录解析器，显式声明 ctypes 参数／返回类型与句柄释放。
- 在现有权限允许时做有界只读实验并记录结果。没有权限时正常返回 unsupported／permission_required，并使用通用通道，不能假报 native_ready。
- 验证文件／父目录 ID 到路径的重建、日志游标、Journal ID 变化、游标失效、截断记录及未知版本；复杂情形如尚未支持需列为缺口。
- 批次提交与 checkpoint 原子关联，事件重放幂等。扫描中断、权限不足、卷离线不可触发批量误删索引。
- 不为了通过测试而创建／调整／删除系统日志；需要额外权限的完整实测留待后续接入阶段。

## P3：验证与报告

至少验证以下情形，使用隔离样本及合成记录：

- 中文／空格／特殊字符名称；目录范围边界；分页不遗漏、不重复。
- 扫描过程中新增／删除；文件更名、目录更名与子树移动；内容修改；重复事件。
- 取消、崩溃／重启后的恢复；数据库事务失败不能推进游标。
- 无权限目录、磁盘离线／恢复、日志过期、通知溢出；补扫后可恢复一致性。
- 索引自己的数据库／WAL／临时输出时不会形成写入监听循环。
- 可验证条件下的链接／重解析点循环和多路径记录。

做一组可复现的至少 10 万条合成目录记录基准，报告：数据量、数据库大小、首批结果耗时、批量写入时间、名称查询冷／热耗时、分页耗时、内存观察、取消响应。记录硬件、Python／SQLite 版本及是否启用 FTS；合成数据库结果与真实扫描结果分开。不要预设“百万文件秒搜”已达成。

只针对本任务产生的样本做真实增量实验。可以只读探测磁盘能力，但不要把整机文件名或正文写进交接报告；报告使用样本路径和统计。
