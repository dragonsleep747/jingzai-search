镜仔搜索 · 使用说明

一句话：把文件拖进来，输个词，就能找到内容在哪一页、哪一条。

★ 最有特色的功能（这几个最好用，先看）

1. 引用预警：库管理 → 高级工具 → 引用预警，自动揪出「引用了已废止文件」的条款，防止还在用过期规定糊弄事

2. 手机配对检索：顶栏点「📱 手机配对」，手机连同一 WiFi 扫码，在手机上也能搜整个库，还能拍照/选文件直接传进电脑库

3. 迷你速查窗：写材料时按 Ctrl+Alt+J，弹出小窗输入即搜，回车把《文件名》第X条 引用直接粘进当前文档，写报告超快。结果两行显示（文件名+章节位置+正文片段，命中词标色），Ctrl+C 只复制不粘贴、Ctrl+O 跳回软件定位、Esc 关窗；空输入按 ↑↓ 翻搜索历史，窗内可直接勾「仅看有效/同义扩展」，小窗可拖动缩放，位置尺寸会记住

4. 剪贴板快存：看到有用的段落复制后按 Ctrl+Alt+M，自动存成文本并建好索引，立刻能搜到，还记下当时在哪个窗口

5. 同义扩展：搜「安全员」连「专职安全管理员」「安全管理人员」一起找到，换个叫法也不漏（顶部勾选「同义扩展」）

6. 十大分类自动归档：文件一拖进来，按文件名自动分到01国家法律 ~ 10其他资料 十个文件夹，库目录永远整整齐齐

7. 条款级定位：结果直接带「第几章第几条」，点「复制引用」一键生成《文件名》第X条 的标准格式

8. 废止管理：过期文件自动标灰、默认搜不到，标记废止时还会提醒哪些文件引用了它

9. 命中分布图：搜索后顶部柱状图显示哪个文件命中最多，柱子越高越相关，点柱子直接跳到那个文件

一、三步上手

1. 把文件拖进软件窗口（Word、PDF、Excel、PPT、图片、txt 都行）

2. 上面的框里输要找的词——不用按回车，停下来就自动搜

3. 单击结果看原文段落，双击直接打开原文件到那一页

二、搜索小技巧

0. 记不住语法：点搜索框右侧的「?」，打开带实例的速查卡，点实例直接填入

1. 一行里同时有两个词：空格隔开，如 安全 培训

2. 两个词找任意一个：中间加竖线，如 安全 | 环保

3. 不要某个词：前面加减号，如 安全 -费用

4. 字打错了也不怕：搜索类型选「模糊」，错一个字也能找到

5. 结果太多：结果上方的小框再输个词，立刻再筛一遍

6. 同义词命中显示橙色（普通关键词是黄色），状态栏会提示扩展了哪些叫法

三、按文号/状态/日期/分类直接筛

1. 按文号：文号:12号（写片段即可，如 文号:安监12号）

2. 按状态：状态:现行 / 状态:废止 / 状态:替代；多个用竖线：状态:废止|替代

3. 按生效日期：日期:2024（整年）、日期:2022..2024（区间）、日期:2023..（某年及以后）、日期:..2023（某年及以前）、日期:2024-03-01（精确到天）

4. 按文件名：名称:差旅（只在文件名里找，不搜正文）

5. 按分类：分类:05-国家标准GB；多个用竖线：分类:01-国家法律|02-行政法规

6. 只输前缀不输正文词 = 直接列出符合条件的文件；也能和正文词混用，如：差旅 状态:现行 日期:2023..

7. 冒号中英文都行；前缀词不会被高亮

四、结果怎么看

1. 同一文件里连着几行都命中，会自动合并成一条，标「N 行相邻命中」

2. PDF、PPT 的命中行带页码（位置如 L45 · P5 = 第 45 行、第 5 页），双击直接跳到那一页

3. 点结果：右边显示完整段落，左边显示属于哪一章哪一条

4. 顶部柱状图：每根柱子是一个文件，越高命中越多；灰色柱子是已废止文件；点柱子跳到该文件首条命中

五、废止和有效文件

1. 文件入库时，软件自动识别文档号和生效日期，不用手填

2. 过期文件标「废止」、灰色显示，默认搜不到

3. 勾上「仅看有效」，只搜现行有效的文件

4. 标记某文件为废止时，软件会提醒哪些文件引用了它

5. 识别错了能改：库管理 → 右键文件 → 编辑元数据

六、文件存哪里

1. 拖进来的文件会复制一份，放在软件旁边的 library 文件夹，原来的删了也不影响

2. 拖入压缩包（zip/7z）会自动拆开，包里每个文件独立入库、各自按内容归类到 01~10 文件夹；包内文件与库里已有的相同内容会自动跳过；压缩包本身不保留（内容已全部入库）

3. 按十大分类分别放在 01~10 的子文件夹里，不会散在根目录

4. 一键打包库：库管理 → 高级工具 → 一键打包库，整个库（文件+索引+OCR识别结果）压成一个 zip，软件本身不带数据、体积不变；换电脑时在新软件里选「从压缩包还原库」，自动重启后整库恢复，不用重新识别，原来的库会自动留在 backup 文件夹兜底

5. 换电脑：把软件文件夹整个拷走也行，或用上面的打包/还原

6. 扫描件和图片要逐字识别（OCR），大文件请耐心等一会

七、常用快捷键

1. Ctrl+Alt+J  呼出「镜仔速查」迷你窗：Enter 粘引用、Ctrl+C 只复制、Ctrl+O 定位、↑↓ 选择/翻历史、Esc 关闭

2. Ctrl+Alt+M  把剪贴板文字快存入库（自动建索引，立刻可搜）

3. Ctrl+F    回到搜索框

4. F5        重新扫描文件夹

5. Ctrl+E    把搜索结果导出成表格

6. F1        打开本说明

7. 全局热键可在 ⚙ → 热键设置 里改；被占用会提示更换

八、其他好用功能

1. 收藏：预览时点「☆ 收藏此条」，顶部「书签」按钮随时找回

2. 收藏汇编：书签窗口 → 导出汇编，收藏的条款自动整理成《常用制度摘编》（带文号、施行日期、章节定位），可直接打印下发

3. 结果汇编：搜完点结果上方「导出汇编」，命中条款自动成稿（带文号、施行日期、章节定位，关键词黄底标注），可直接打印

4. 版本对比：库管理 → 高级工具 → 版本对比，挑两个文件左右对照；也可在库管理或搜索结果里右键 → 与旧版对比，自动认出同名旧版本并排打开，删改之处红绿标出

5. 引用跳转：正文里蓝色的《文件名》点一下，跳到被引用的文件；红色说明对方已废止

6. 分类自查：库管理 → 高级工具 → 分类自查，列出未分类和可能归错的文件，一键修正，文件自动搬进对应文件夹

7. 查重清理：库管理 → 高级工具 → 查重清理，自动找出重复文件，保留最新的

8. 自定义同义词：⚙ → 同义词库设置，加本单位叫法（如 安环部 = 安全环保部）；「内置词组…」可看自带的 16 组

9. 命令行唤起：镜仔搜索.exe /s "关键词" 启动即搜；重复启动不会开第二个窗口，自动转给已运行的实例

10. 开机自启动：⚙ → 勾选「开机自启动」，开电脑自动运行（手机检索服务也自动开启）

11. 网页唤起：软件启动时已自动注册 jingzai:// 协议，浏览器打开 jingzai://search?kw=关键词 即可在软件里搜索

12. 扫描入库：点「扫描入库」选文件夹，里面所有文件自动入库；F5 随时重扫

13. 深色模式：⚙ 菜单勾选「深色模式」；预览按住 Ctrl+滚轮缩放字号；底部「自适应换行」可把 PDF/Word 硬断行重排铺满窗格，关掉即逐行原样

14. 引用关系图：⚙ → 生成引用关系图（HTML），离线网页不依赖网络。默认「分层看前后」——依据在最上层、细则在最下层，箭头指向被引用文件；可切「力导向看聚类」看同分类抱团。单击节点高亮它的依据/引用者，右侧名称继续点能沿引用链追溯；双击节点只展开它 1~3 层引用链，再双击空白恢复全库；滚轮缩放、拖拽平移，放大后自动显示文件名

九、关闭与后台运行

1. 点右上角的叉：本次启动第一次会先问「最小化到托盘」还是「直接退出」，选完这次就一直照这个来，不会再问

2. 只影响本次运行：彻底退出程序后，下次打开还会重新问一次

3. 选「最小化到托盘」：窗口收进系统托盘、后台继续运行，手滑点了也不会把正在跑的入库任务关掉；双击托盘图标，或右键托盘图标 → 显示主窗口，即可唤回

4. 选「直接退出」：结束程序；若入库等长任务还在跑，会先确认一次再退

5. 询问框上直接关掉（或按 Esc）＝取消，什么也不做

6. 想立刻彻底退出、不想等问答：右键托盘图标 → 退出程序

7. 收进托盘后全局热键照常可用；用 镜仔搜索.exe /s "关键词" 或浏览器打开 jingzai:// 链接，会自动把主窗口调出来
