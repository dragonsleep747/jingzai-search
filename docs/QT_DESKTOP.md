# 镜仔搜索新版桌面端

新版通过 Qt Widgets 提供标准 Windows 窗口，复用现有 SQLite 索引、检索、文档解析和引用生成模块。旧版程序与 config.json 保持原样，新界面设置保存在资料库目录下的 config.qt.json。

## 启动与构建

```powershell
.\.venv-qt\Scripts\python.exe search_app\qt_main.py
.\.venv-qt\Scripts\python.exe search_app\qt_main.py --data-dir .\data --search 安全
.\tools\build_qt.ps1
```

开发环境使用 `python -m venv --system-site-packages .venv-qt`，随后安装 PySide6。这样可复用原项目已安装的 Office/PDF/OCR 组件。分发使用目录版，EXE 与 `_internal` 文件夹放在一起，可避免每次启动重新解压大型依赖。

## 数据兼容

- 自动查找 EXE 所在目录及其父目录中的 index.db。`--data-dir` 可指定另一资料库。
- 搜索直接使用 searcher.search/search_fuzzy 和 aggregate_results，不迁移或重建既有索引。
- 收藏、文号、状态、分类和正文均沿用原数据库结构。
- 新设置独立保存；自动监听仅对已选定的资料文件夹启用。
- 资料包可还原到独立空文件夹；文件菜单另有原位还原，先校验暂存资料，再退出切换并重启，原库保存在 backup。

## 功能入口

| 功能 | 位置 |
|---|---|
| 精确/模糊、类型、有效状态、同义词、查询语法 | 搜索页 |
| 结果内筛选、章节、上下文/整段/分段全文、行号跳转 | 搜索页折叠选项与正文顶部“⋯” |
| 复制正文、规范引用、收藏、打开原文件 | 正文顶部“⋯” |
| 文件索引、复制导入、文件夹扫描、拖入文件 | 添加资料 |
| 元数据编辑、重命名、重新索引、仅移除索引 | 资料库 |
| 查重、失联、分类规则/自查、双文件版本对比、标准检查 | 资料库 → 更多操作 |
| 收藏备注、导出收藏汇编 | 收藏 |
| 进度、停止、错误详情、失败文件重试 | 菜单 → 任务与进度 |
| 本机 Ollama 问答、流式回答、引用依据、语义索引 | 镜仔智答 |
| CSV/Word 导出、文档引用关系、关系图、AI 分析结果 | 搜索列结果数量旁“⋯” |
| 联网查询/下载、手机访问、备份/还原、专项工具 | 菜单 → 工具中心 |
| 深色、字号、自动监听、热键、模型配置、自定义同义词 | 菜单 → 设置；关闭时选择托盘或退出 |

功能完整性以 [旧版功能对照](QT_PARITY_REVIEW.md) 为准。主界面、常用管理和入库预检使用 Qt；完整 AI、联网检索等高级工具在独立进程运行原来的完整界面，菜单明确标记，尚未全部移植成 Qt。第一轮体验提升见 [使用说明](QT_EXPERIENCE_V1.md)。

子窗口默认控件 11pt、长文 12pt，在设置里可分别调整。兼容工具支持原生 DPI 绘制，重新打开后应用新字号；设置表单可滚动。详见 [子窗口清晰度与阅读调整](QT_DISPLAY_COMFORT.md)。

最新界面采用四个侧栏入口和底部菜单，顶部业务菜单已归位。搜索框与折叠选项在结果列，正文采用通高布局，阅读操作与位置合并成一条细栏。完整功能去向见 [极简界面说明](QT_MINIMAL_UI.md)。

查重可执行索引清理或回收站操作；分类自查可修正、忽略和撤销。PDF 优先用 Sumatra/Acrobat/Edge 定位页码；Word/WPS、Excel/PPT 通过 Office 接口定位，缺少支持时回退并提示。手机窗口支持一次性扫码免口令配对。

## 窗口实现

- 使用 QMainWindow 的系统标题栏、边框、缩放、贴靠与最小化/还原行为。
- 主窗口不设置透明度、不使用无边框窗口、不替换窗口过程、不创建截图遮罩。
- 搜索、预览、索引和网络操作使用后台线程；跨线程结果通过 Qt 排队信号送回界面线程。
- 新搜索可取消旧搜索，预览和结果按请求序号防止旧任务覆盖新页面。
- 长文全文模式按当前位置分段加载；结果树分批创建，避免大量命中卡住窗口。
- Windows 版本查询使用标准库的原生 API 回退，避免 WMI 不响应时阻塞 OCR 初始化。

## 验证

```powershell
.\.venv-qt\Scripts\python.exe search_app\tests\run_tests.py
.\.venv-qt\Scripts\python.exe search_app\qt_main.py --data-dir .tmp\qt-verify-data --verify-native .tmp\qt-verify-report
```

原生验收使用独立临时库，检查搜索、预览、收藏、列表以及 20 次普通/最大化、浅色/深色窗口恢复。通过桌面像素采样检查预览区的大面积纯黑，屏蔽其他窗口遮挡的样本；报告保存为 result.json，界面截图同时保留。此检查不等于对所有显卡、系统设置和窗口区域的穷举验证。
