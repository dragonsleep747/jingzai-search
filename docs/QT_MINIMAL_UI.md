# 极简阅读界面 · 2026-10-28

本轮只调整界面和入口，不把自然语言智能找文件宣称为已实现。检索、资料库和完整高级工具继续沿用现有能力。

## 三列布局

- 第一列仅保留搜索、资料库、镜仔智答、收藏及底部“菜单”。任务、工具、设置、启动与唤起、帮助收进菜单；进行中的任务数量显示在菜单按钮上。
- 第二列承载搜索框、搜索按钮、默认收起的“选项”、结果和排序。历史图标在输入框右侧。搜索匹配、文件格式、状态、同义词、大小写、文号、名称、分类、日期、布局和语法示例都可在选项中找到。
- 第三列通高阅读，顶部仅一条 34 逻辑像素的细栏，合并文件名、位置、命中跳转、专注阅读和“⋯”。不再设置独立的底部位置栏及全局状态栏；操作通知短暂显示后自动消失。
- 文件名点击查看路径和元数据；位置点击跳转行号或 PDF 页码。Ctrl+Shift+R 临时收起结果列，再次操作恢复原宽度及内容。
- 保留系统标题栏、边框、最小化／还原、贴靠和最大化行为，不使用透明主窗或截图遮罩。

## 命中片段

短片段完整显示，长片段按实际列宽换行、默认最多三行，优先展示命中词附近。“展开”增加显示高度，“收起”恢复；极长内容每次继续显示 24 行。每份文件先展示五组命中，其余由“还有 N 处命中”继续展开。均保留完整文字和原始位置，不以固定字数替换原内容。

结果列共用一个滚动条。展开片段不重新打开正文、不改变右侧阅读位置；空间键也可展开／收起当前片段。结果内筛选会检查尚未展开的命中，避免新分页方式遗漏结果。

## 功能去向

| 功能 | 当前入口 |
|---|---|
| 精确／模糊、类型、有效状态、同义词、大小写、文号／名称／分类／日期／状态 | 搜索列 → 选项；有生效条件时显示数量和悬停摘要 |
| 历史、常用搜索、保存条件、恢复阅读 | 搜索框右侧历史图标 |
| 结果内筛选、命中分布、结果导出、文档引用关系、关系图、分析当前结果 | 结果数量旁“⋯” |
| 目录、行号、整段／上下文／全文、提取文字／原始 PDF、自适应换行、字号、复制、引用、收藏、原文件 | 正文顶部“⋯”；原有快捷键保留 |
| PDF 缩略图、页码、缩放、页内查找 | 正文“⋯”→ PDF 页码／缩放／查找；顶部位置也可直接跳页 |
| 添加、扫描、待入库审核、剪贴板快存 | 资料库 → 添加资料；拖入及全局快存热键保留 |
| 编辑、批量信息、索引、重命名、移除、查重、问题文件、分类自查／规则、台账、双文件／自动对比、标准检查 | 资料库 → 编辑信息／更多操作 |
| 收藏备注、打开条款、导出汇编 | 侧栏 → 收藏 |
| 完整问答、模型管理、语义索引、多轮历史、来源和导出 | 侧栏 → 镜仔智答，继续运行完整兼容工作台 |
| 任务进度、停止、详情、错误与重试 | 菜单 → 任务与进度 |
| 备份、独立还原、原位还原、软件与资料完整打包、资料目录 | 菜单 → 工具中心 → 资料安全 |
| 引用预警、合规扫描、索引体检、OCR、下载监控、存档目录、完整同义词库 | 菜单 → 工具中心 → 检查与配置 |
| 联网查找、手机配对、迷你速查、粘贴文本反查 | 菜单 → 工具中心 → 辅助检索；速查热键及托盘捷径保留 |
| 已有新版界面的旧版替代流程 | 菜单 → 工具中心 → 旧版备用 |
| 外观、正文和子窗口字号、监听、自动备份、热键及模型配置 | 菜单 → 设置 |
| 开机启动、协议唤起 | 菜单 → 启动与唤起 |
| F1 完整说明、功能位置表、反馈 | 菜单 → 帮助 |

工具中心支持按分组和名称查找。功能位置说明改为只读指引，避免再提供一整套重复启动入口。兼容备用默认不与主要工具列表混排。

## 验收范围

- 自动测试覆盖现有功能及新布局、选项展开、任务与工具路由、长片段鼠标展开、分页后筛选、日期范围保留与专注阅读。
- 100%、125%、150%、200% 模拟缩放检查中，正文净高度占客户区约 94.7%–96.1%；选项展开时正文高度不变。本机实际缩放为 125%，其他档位是模拟检查，不代表多显示器穷举。
- 最终 EXE 另做 Office／PDF／OCR 样本解析、完整兼容工具启动及 20 次最小化／恢复检查。结果和构建哈希见 QT_ACCEPTANCE.md。
- 自然语言智能找文件后续在同一输入框接入；本轮保留现有精确及容错搜索，不提供未接通的“智能搜索”开关。

截图与布局报告位于 `.tmp/minimal-layout-*`；最终程序的实测证据保存在发布目录“验收资料”。
