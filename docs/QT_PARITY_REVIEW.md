# 旧版功能对照与补齐记录

依据：旧版 F1 完整使用说明（LEGACY_USER_GUIDE.txt）、旧版使用说明 和对应源码。上一轮核心测试和窗口测试不能证明功能齐全；本记录纠正此前把首版称作完整交付的说法。

## 验证边界

- 自动测试覆盖原引擎回归及输入即搜、快存可检索、完整预检分发、定位参数、设置并行合并、章节范围、高亮/引用、清理失败保护、备份、软件包、还原/回滚和 HTTP 一次性配对。
- 兼容工具检查真实窗口和回调异常；迷你速查额外验证真实检索/引用，粘贴系统调用用记录器替代，防止写进用户文档。导入检查到达“确认入库”。
- 最终 EXE 的 Office/PDF/OCR 解析和 20 轮恢复另做原生验收。屏幕采样只证明本机本次未遮挡正文区域的表现。
- 联网网站、真实 Ollama 模型生成、实际手机、不同版本 Office/WPS 尚未逐一完成真实环境验收。工具启动成功不等于所有外部条件均已验证。

高级工具仍用旧界面，后续移植须按此表替换并重验。本次不把“所有功能已用 Qt 重写”作为结论。
