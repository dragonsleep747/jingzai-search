# 下一版界面与多模态检索方案（待实施）

2026-10-28。本文件保留最近一次界面提案，并补充智能查文件与镜仔智答的职责定义。它是方案文档，不代表正式程序已实现下面的能力；本轮不修改程序、启动全盘索引或安装模型。

## 保留的界面方案

- 侧栏仅“搜索、资料库、收藏”三个文字入口，不加导航图标；底部为菜单。
- 智答迁入搜索区域。第二列共用输入框，左端小下拉切换“查文件／问资料”；查文件以框内放大镜执行，问资料以同尺寸发送按钮执行。
- “选项”改为“筛选”，默认折叠；去掉常驻相关程度下拉，排序归入“结果”菜单。
- 结果菜单按排序、查找与显示、导出、交给智答分析分组。
- 底部菜单保留任务、工具、设置、帮助，退出单独分隔。启动与热键归设置；工具中心按用途分组。
- 正文顶部的“⋯”改为“阅读”，按复制、显示、跳转、当前文件分组，最多两层。无关的文件类型操作按条件隐藏。
- 继续保留通高正文、单条细工具栏、可展开命中片段及专注阅读。

## 重新定义能力

查文件：输入准确关键词、模糊记忆或画面描述，返回实际存在的文件及命中位置。最终覆盖文件名、正文、图片画面、文档内插图、视频画面、语音转写等不同内容；依类型分期实现。

镜仔智答：根据检索结果或选定资料，进行回答、总结、对比和解释。结论关联原文、原图或视频位置，能够回到依据；保留模型管理、索引状态、多轮历史、停止与重答、导出等既有功能。普通聊天保留为明确选择的使用方式，默认围绕资料回答。

两者共用文件身份、内容索引与位置标记。搜索负责发现候选，智答负责理解和组织回答；不另建一套与搜索脱节的智答资料库。

## 例子：女孩抱着小狗

| 结果类型 | 匹配依据 | 预览与定位 |
|---|---|---|
| 照片、截图、插画 | 画面主体与动作关系 | 缩略图、原图缩放、来源路径 |
| 视频 | 某个片段中的画面 | 匹配帧、时间点，点击播放到该位置 |
| PDF、Word、PPT | 页内图像或嵌入插图 | 文件名、页码／幻灯片／插图所在位置 |
| 正文或字幕 | 文字提及该场景 | 高亮片段与原文位置，标记“文字提及” |
| 音频 | 语音中提及该场景 | 转写片段与时间，标记“语音提及” |

“画面出现”和“文字／语音提及”需要区分显示。音频中提及该场景不等于存在对应画面。

先检索候选，再对靠前结果核验主体与关系，减少“女孩站在狗旁边”“女孩牵狗”“男孩抱狗”等误匹配。相似候选与依据不足的结果分开呈现；相关度不包装成准确率。

## 搜索与追问的衔接

1. 查文件输入“女孩抱着小狗”，展示真实文件、缩略图和命中依据。
2. 继续输入“只要白色小狗”“不要插画”，作为本次检索条件收窄结果，可撤销条件。
3. 选择结果后切换问资料，提出“这些素材有什么区别”“这份 PPT 在哪里用了这张图”。
4. 智答输出带来源的解释，点击来源返回右侧原图、页码或时间点。

第二列按结果内容使用文字列表或缩略图卡片；右侧自动切换正文、原图、PDF 页面或视频。问资料时可适度加宽中间列，右侧继续保留来源预览；切回后恢复原布局。

## 搜索范围与索引

- 范围支持现有资料库、指定目录，以及配置后的全电脑可检索位置。
- 全电脑检索以可访问、已索引、已支持的文件内容为边界。界面显示范围、索引进度、尚未处理和无法解析项，不把“没索引”显示成“没有相关文件”。
- 首次后台建立索引，后续增量更新；可暂停。视频先取关键画面，再对命中附近细查，仍需评估短暂画面的漏检。
- 同一文件的多个命中合并展示；重复内容分组，但保留实际路径与副本位置。
- 默认本机处理。模型选择、首次索引耗时与存储需求在实施前结合实际硬件验证，不预先承诺全盘秒级处理。

## 分期与验收

第一期：保持原精确／容错搜索，接入中文描述找文档与独立图片的画面检索，贯通搜索、原图预览和带依据的智答。先把“女孩抱狗”的照片场景做可靠。

第二期：接入 PDF、Word、PPT 中的图片及视频画面，完成页内位置与时间点跳转。

第三期：接入音频／字幕、以图找图和自然语言条件追问，完善跨类型资料分析。

验收样本须同时包含正确结果和易混淆反例：女孩抱狗、女孩牵狗、女孩在狗旁边、男孩抱狗、只有文字提及等。逐项检查结果质量、索引覆盖、定位、取消与增量更新、界面响应，以及既有功能回归。语义检索不承诺找全所有相关内容。
