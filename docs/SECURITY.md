# 镜仔搜索 · 安全说明

> 版本：v1.1.0 · 适用对象：单机 Windows 桌面端 + 局域网手机网页访问。

## 威胁模型

| 对象 | 风险 | 现状 |
|------|------|------|
| 本机数据 | 索引库明文存储文档全文 | `index.db` 不加密，依赖 Windows 账户级文件权限（单用户机器可接受） |
| 局域网访问 | 同网段设备扫描/连接 17891 端口 | 需扫码配对 + 长期令牌，防爆破锁定 |
| 命令入口 | `jingzai://` 协议被恶意网页/脚本调用 | 关键字长度截断 200 字符，仅触发本地搜索 |
| 供应链 | 解析器处理恶意文档 | 所有解析失败落入错误表，不执行文档内代码 |

## 认证与会话（mobilesvc.py）

- **扫码配对**：手机首次访问须扫电脑端二维码完成一次性配对，凭 token 登录
- **令牌比较**：使用 `hmac.compare_digest` 常量时间比较（mobilesvc.py:2209），防时序侧信道
- **会话**：登录后签发 `jztoken` Cookie，`HttpOnly`，有效期 30 天
- **防爆破**：同 IP 连续 5 次失败锁定 60 秒（`FAIL_LIMIT=5` / `FAIL_BLOCK=60`，mobilesvc.py:2142–2165）
- **请求体大小限制**：各上传/粘贴端点均有 `MAX_BODY` 上限，拒绝超大请求

## 配置与密钥

- 访问令牌存储于 `config.json`，该文件已被 `.gitignore` 排除，**不进入版本库**
- 历史审查：旧令牌 `[redacted]` 虽曾暂存，但 `git log --all -- config.json` 为空 —— **从未进入 git 历史**；本次加固已轮换为新值（v1.1.0）
- 配置读取使用 `utf-8-sig`（main.py:195），兼容带 BOM 的 UTF-8 文件；保存同样带 BOM 防损坏
- 生产代码中无硬编码绝对路径，可整体迁移

## 输入硬化（ipc.py）

- `jingzai://` 协议与命令行传入的关键字统一截断至 `MAX_KW_LEN=200`（ipc.py:22，截断 ipc.py:69），防超长字符串
- 协议 URL 先做 URL 解码再做参数解析，非法输入一律忽略（`test_ipc.py` 覆盖）
- 所有数据库访问为参数化 SQL（FTS5/参数绑定），无字符串拼接注入面

## 剩余风险（已确认，属产品定位）

| 风险 | 说明 | 缓解建议 |
|------|------|----------|
| 局域网 HTTP 明文 | 手机端走 `http://IP:17891`，无 TLS，同网段可嗅探 | 仅在可信局域网使用；未来可加自签 TLS |
| 本地配置明文令牌 | token 以明文存于 `config.json` | 同账户权限可读；属单机应用常态 |
| 索引库未加密 | `index.db` 含文档全文 | 硬盘级 BitLocker 可兜底 |
| 上传/OCR 端点同令牌 | 移动端上传与检索共用同一会话令牌 | 未来可加只读令牌分级 |

## 回归保障

安全相关行为已纳入测试套件（`search_app/tests/test_ipc.py`）：协议解析、URL 解码、超长关键字截断、非法输入忽略。加固后的行为变更须同步补用例。
