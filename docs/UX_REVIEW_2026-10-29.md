# 镜仔搜索：实际体验、整改与复测

日期：2026-10-29。对象：当前“探索／智答＋0.3.1 阅读交互”新版。

本轮体验评分 **7.2 / 10 → 8.6 / 10**。这是同一评审者根据实际任务完成情况、操作路径、状态反馈与阅读连续性给出的主观评分，不是用户调查结果，也不把测试通过率换算成满意度。

## 已解决的问题

| 问题 | 用户影响 | 已落实的修改与验证 |
|---|---|---|
| 电脑搜索范围藏在筛选里 | 初次使用不知道怎样开始找电脑文件 | 搜索框下方直接显示当前范围，菜单可切换电脑位置、原资料库和两者，并进入位置管理；空白页说明建立目录的步骤 |
| 合并范围没有正文排序入口 | 旧版已有的相关程度、命中次数等在默认搜索模式中难以使用 | 合并范围分别显示正文结果排序和文件目录排序；正文排序立即作用于列表，实际验证名称／命中次数两种顺序 |
| 合并范围的命中分布为空 | 开启分布图仍看不到命中，也无法定位相应结果 | 按真实正文结果更新分布，点击柱形同步选中、展开和定位对应文件 |
| 目录排序清空结果内筛选 | 排序后需要重新输入筛选，容易误以为结果变化 | 排序保留筛选文字与预览，验证筛选后的可见文件数量及阅读没有重新加载 |
| 继续加载重置阅读列表状态 | 已折叠文件重新展开，展开的长片段及加载过的更多命中丢失 | 保存并恢复折叠状态、已加载命中、片段展开高度、所选行与滚动位置；专门验证 100 项后的继续加载 |
| 切换到智答仍展示搜索筛选 | 无关设置挤占回答区，模式关系不明确 | 智答隐藏搜索筛选、范围、分布及结果内筛选；返回探索恢复原筛选展开偏好 |
| 智答没有持续状态，停止按钮始终可用 | 难以判断正在连接、生成、已结束还是失败 | 增加准备／连接／生成／完成／停止／失败状态，空闲时禁用停止；真实模型验证停止后不再追加内容 |
| 后台覆盖信息刷新抹去检索失败提示 | 用户可能把不完整检索当成完整结果 | 统一生成结果状态，失败标志持续保留，悬停可查看原因；强制失败后再次刷新覆盖信息验证 |
| 停止范围后仍留在周期更新集合 | 停止可能很快被后台定时器自行恢复 | 手动停止或移除范围时退出本会话自动更新集合；验证执行下一轮周期更新不会重新提交该范围 |

本轮记录的上述九类问题均已有修改和对应复测。未把“没有发现更多问题”描述为所有电脑和所有场景均无缺陷。

## 实际体验与测试证据

- 使用 Windows 原生 Qt 窗口和真实控件事件操作，并保存窗口截图；不是只阅读源码或仅以假模型演示。桌面截图工具用于观察已发布程序的启动界面。后续操作采用隔离原生窗口，避免影响用户正在使用的其他软件。
- 修改前八个专项场景均可复现失败；修改后最终十二项专项检查全部通过。后来增加的四项覆盖排序效果、长片段保留、停止范围和验收程序收尾，未伪造它们的修改前失败记录。
- 最终全量 **362 项测试全部通过**；日志见 [最终全量测试](../.tmp/ux-review/final-full-tests.log)，[原生专项复测](../.tmp/ux-review/final-native-ux.log)，[修改前记录](../.tmp/ux-review/before-tests.log)。
- 真实原生使用流程共 **13 项通过**：范围建立、100→200→205 项加载、正文阅读、命中分布、收藏、复制引用、真实模型有据问答、点击来源、普通聊天、停止生成，以及资料库／收藏保持正常。详见 [流程结果](../.tmp/ux-review/live/result.json)。
- 本机真实模型为 `qwen2.5:7b-instruct`。样本规定纸质借阅期限为“五天”，模型按正文回答“五天”并列出可点击来源；普通聊天和中途停止均实际执行。
- 本次小样本合并检索约 **312 ms**，包含事件处理及界面等待；真实模型回答首次可见文字约 **5.61 秒**。这些是单次观测，不是全盘性能基准或普遍响应承诺。
- 打包后的 EXE 原生验收通过：DOCX、XLSX、PPTX、PDF、PNG/OCR；导入预检、保留两份、仅登记路径；PDF 翻页、缩略图、正文切换；浅／深色、文本／PDF 共 **20 轮最小化与恢复**。详见 [EXE 验收](../.tmp/ux-review/final-package-native/result.json)，[进程退出回执](../.tmp/ux-review/final-package-exit.json)。
- 对真实旧资料库做只读查询对照：193 份文档，四组查询结果与旧引擎一致。详见 [来源与资料库对照](../.tmp/ux-review/source-and-library.json)。

## 交付与使用

继续从工作区 `镜仔搜索新版/镜仔搜索新版.exe` 或原来的“镜仔搜索新版”快捷方式启动。更新程序前完整保留旧程序目录，备份位置和 EXE 哈希记录在同目录 `体验优化交付.json`。

新增入口就在搜索框下方“位置 + 资料库”。点击后可以直接切换范围或进入电脑搜索位置管理。合并范围下，“⋯”里可以分别设置正文结果与文件目录的排序。

正文、目录、导入和 AI 的测试写入均在 `.tmp/ux-review` 隔离资料库；本轮没有把体验样本加入用户正式资料库。正式资料库仅进行了只读查询对照，程序更新沿用现有资料和设置。

## 评分尚未达到十分的原因

高级工具部分仍采用原有兼容工作台，跨界面的视觉和操作一致性尚不完整。本轮没有重新实现这些工作台，已有能力的回归结果单独列明。

探索目前搜索文件名／路径，正文依赖既有资料库；全电脑图片、视频和语音的自然语言语义理解属于尚未实现的产品能力。不能把“目录已建立”解释成这些内容已经完成分析。

本轮没有逐一实测真实手机、所有外部网站、不同版本 Office/WPS、多显示器和所有磁盘规模。这里保留明确边界；这些未覆盖项没有写成已通过，也没有计为本轮已修复的问题。
