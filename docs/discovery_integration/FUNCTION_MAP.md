# 功能入口迁移表（探索／智答候选版）

> 当前位置更新：智答现已嵌入搜索工作区第二列，来源在右侧预览；旧版完整工作台在“智答设置”内保留。搜索结果分析进入新版智答，正文顶部使用“阅读”，启动与唤起在“设置”子菜单。当前使用方法见 [USER_GUIDE_0_3.md](USER_GUIDE_0_3.md)，历史映射表保留如下。

依据：旧版使用说明（LEGACY_USER_GUIDE.txt）、旧版使用说明、QT_PARITY_REVIEW.md，
并纳入本轮“探索/智答”入口变化。“原生”= 新版 Qt 直接提供；“兼容”= 打开旧版
独立进程完整工具。**本轮已实现的新入口用 ✅ 标记并写明验证状态；未验证的写
“未验证”，不把工具能打开当作功能已全量验证。**
