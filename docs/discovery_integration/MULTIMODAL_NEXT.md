# 多模态后续接入设计（F 项盘点与设计，不实现）

状态：**设计文档**。目录检索完成不等于“输入女孩抱着小狗找到照片/视频/插图”。
本轮未安装模型、未下载、未上传、未建远程调用；未把任何画面/OCR/视频能力作为
可用搜索方式对用户展示。

## 1. 现有能力盘点（2026-10-28 实测/代码级确认）

| 能力 | 现状 | 可复用组件 | 备注 |
|---|---|---|---|
| 正文检索 | ✅ 已接入，基线 289 项回归 | `searcher.py`、`indexer.py` | 按词/同义词/文号/日期/分类 |
| OCR（扫描件文字） | ✅ 代码存在；RapidOCR（内置中英模型）+ Tesseract 回退 | `parsers.py: _ocr_image / parse_image` | OCR 产出的是文字，不是“画面出现” |
| PDF 页渲染 | ✅ QtPdf 缩略图/页面渲染 | `qt_frontend/pdf_reader.py` | 可输出页面位图，未做画面特征 |
| 语义向量（文字） | ✅ 代码存在；Ollama `bge-m3` 嵌入 | `ai_qa.py: embed_texts / semantic_search` | 只对文字块；需要本机 Ollama + 模型 |
| 图片文件识别（OCR 文字） | ✅ `parse_image` → OCR 文本入库 | `indexer.py` / `parsers.py` | 图片里“有文字”可搜，画面主体不可搜 |
| 文档内插图 | ❌ 未提取 | 需扩展 `parsers.py` | PDF/Word/PPT 内嵌图当前不单独索引 |
| 视频帧 | ❌ 未实现 | 需 ffmpeg/OpenCV 抽帧（未引入） | 本机是否可用未验证 |
| 音频/语音转写 | ❌ 未实现 | 需 ASR（faster-whisper 等，未引入） | 本机是否可用未验证 |
| 画面/多模态理解（图像向量/图文对齐） | ❌ 未实现 | 见第 3 节候选 | 不下载不安装 |

结论：**文字提及**通道基本具备（正文/OCR/向量），**画面出现**通道完全缺失，
文档内插图/视频/音频也缺失。不能把“文字提及女孩抱狗”当作“画面出现”。

## 2. 统一文件身份 / 内容版本 / 位置契约

- 目录层身份沿用 `catalog.db`：`entries.entry_id` + `objects.object_id`
  （`f:<128bit hex>`）+ `source_id`。更名只改路径不改 object_id；内容变化递增
  `entries.content_version`（已有：modified 递增、renamed 不变）。
- 内容分析层建议新增独立分析队列表（不塞进目录库）：
  `analysis_jobs(object_id, content_version, page/image_seq/time_sec, status, model, ts)`；
  订阅 `catalog` 的真实变更：更名不重算特征，内容变化重算，硬链接多路径共用
  object 但不重复算（路径分别保留）。
- 位置契约：独立图片 → 文件；PDF/Office 插图 → `(path, page_no, image_seq)`；
  视频 → `(path, time_sec)`；音频 → `(path, time_sec)`；正文/字幕 → `(path, line_no)`。
  UI 的“回到依据”统一解析这一契约。

## 3. 本地模型/推理候选（盘点与建议，均未安装）

依据官方文档/论文，日期 2026-10-28；性能只给量级，不给秒级承诺。

| 候选 | 用途 | 许可证 | 体积量级 | 显存/内存 | CPU 可行性 | 中文描述 |
|---|---|---|---|---|---|---|
| CLIP ViT-B/32 | 图像向量/图文对齐 | MIT（权重另有条款） | ~400 MB | 低 | 可（慢） | 中文弱 |
| OFA-Sys Chinese-CLIP | 中文图文对齐 | MIT（权重另有条款） | ViT-B ~400 MB | 低 | 可 | 好 |
| SigLIP | 图像向量 | Apache-2.0 | ~数百 MB | 低 | 可 | 需中文微调/搭配 |
| MobileCLIP | 移动端图像向量 | 官方开源 | 更小 | 很低 | 可 | 中文弱 |
| Qwen2-VL / Qwen2.5-VL（小尺寸） | 图文理解/描述 | Apache-2.0 | 数 GB | 数 GB 显存，CPU 慢 | 小模型勉强 | 好 |
| faster-whisper | 音频转写 | MIT | 数百 MB | 低 | 可 | 中文一般，方言差 |

结论建议：首期用 **Chinese-CLIP 或 CLIP+中文微调**做图像向量（CPU 可行、体积可控），
必要时用本地小 VLM 只对靠前候选核验主体/动作关系；视频用 ffmpeg 抽关键帧（另行引入，
需许可证/体积/分发说明）；音频用 faster-whisper。**本轮一律不安装、不下载。**

## 4. 分期接入顺序

1. **独立图片**：图像向量 + 中文描述查询（先做“画面出现”）；区分“文字提及”
   （OCR 命中）与“画面出现”（向量/理解命中），相似度不包装成准确率。
2. **文档内插图**：PDF/Word/PPT 页内图提取，位置 `(page, image_seq)`，先 PDF。
3. **视频**：关键帧抽帧 + 命中附近细查；报告时间点。
4. **音频/字幕**：转写片段与时间，标记“语音提及”。

## 5. 隔离验收集（女孩抱狗）

样本必须同时包含正例与易混淆反例：

- 女孩抱狗、女孩牵狗、女孩站狗旁、男孩抱狗、只有文字提及（无画面）。
- 逐项记录：候选排序、误检/漏检、文件/页/帧定位、增量（更名不重算、内容变化重算、
  硬链接不重复算但路径保留）。
- 验收门：报告“画面出现”与“文字/语音提及”分开；相似度不冒充准确率；未实现能力
  不展示为可用搜索方式。
