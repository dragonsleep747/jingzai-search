# 0.3.1 阅读交互修复

日期：2026-10-29。本轮针对用户截图中的结果换行、文件标题折叠和正文引用跳转问题。

- 第二列的命中数列固定为 48 个逻辑像素，取消最后一列自动拉伸。命中片段跨列使用整行宽度，排版与点击区域使用一致的宽度；拖动列宽后自动重排。
- 文件标题单击展开／折叠，箭头仍可使用，空格也可切换。折叠当前文件不重置第三列阅读位置；选择另一文件仍能预览，双击保留打开原文件。
- “还有更多命中”替换原加载入口，不再重复添加同一批片段。
- 蓝色引用单击查看对应资料并定位条款；引用指向当前文件时，直接调用原文件打开与定位功能，避免看起来没有反应。Ctrl+单击任意引用可打开源文件。
- 引用右键菜单提供软件内查看、打开源文件、所在位置和复制路径；悬停显示目标路径。同一文件的不同条款引用各自定位。
- 修正更换关键词仍命中同一文件时，预览可能保留上次关键词和位置的问题。

## 验证

新增 11 项实际 Qt 鼠标／键盘回归，覆盖宽度、拖动重排、标题与箭头点击、分页入口、同文件关键词刷新、引用跳转／返回、Ctrl+单击及不同条款定位。全量 **350 项全部通过**。

使用真实资料库的隔离副本，以用户截图中的“安全生产费用”复测 22 个文件结果。当前样本结果视口宽度 301、片段宽度 277、计数列宽度 48（均为逻辑像素）；片段保留树形缩进，其余宽度用于文字。展开／收起截图和测量见 `.tmp/reading-ui-fix/`。

打包程序完成 151 项检查与 20 轮系统窗口最小化／恢复；详细帧统计、源码／程序哈希、备份和发布信息见 reading-fix-manifest.json。引用打开行为依赖用户安装的阅读器，支持的程序可自动定位；其他程序按系统默认方式打开。

正式新版仍位于 `镜仔搜索新版/镜仔搜索新版.exe`。发布前保留完整程序备份，用户资料库和配置不参与程序替换。
