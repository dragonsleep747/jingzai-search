# 探索／智答版使用说明

更新日期：2026-10-29。

仍从原来的“镜仔搜索新版”入口启动。原资料库、收藏和设置继续使用。

## 找电脑里的文件

1. 进入“搜索”，输入区选择“探索”。
2. 打开“筛选 → 搜索范围管理”，添加目录或勾选磁盘，对需要的位置选择“开始建立目录”。
3. 在“检索范围”选择“已选电脑位置”或“两者”，输入文件名／路径中的关键词。
4. 结果多时点“继续加载”；在“阅读”中打开原文件、所在位置、复制路径或加入资料库。

文件保留在原处。目录已发现只代表名称／路径可搜，正文、画面和语音不自动完成分析。默认跳过系统内部目录，链接目录不递归；无权限或离线位置会保留覆盖说明。

范围面板可以停止、更新或移除范围。移除只移除目录记录。勾选“启动后继续已选范围，并在后台更新”可在下次启动恢复；保持当前会话运行时已建立的目录持续跟踪变化。

## 搜索资料正文

在“筛选 → 检索范围”选择“原资料库”或“两者”。精确／错字容错、同义词、分类、文号、状态等条件仍在筛选中。目录和正文结果可合并，正文命中片段可以展开，右侧继续阅读。

结果“⋯”菜单提供排序、筛选和导出。CSV 导出已加载的文件结果；Word 汇编用于正文命中。

## 使用智答

输入区切换“智答”，选择基于资料或普通聊天，按回车／发送按钮提问。输入过程中不会自动发送。点击回答来源可在右侧查看正文，停止按钮中止当前回答。

先配置本机模型服务。模型管理、完整历史、重答和高级导出仍可通过“智答设置 → 模型与完整智答工作台”使用。尚未分析正文的电脑文件不能直接作为可靠回答依据，需要先按原入库流程加入资料库。

当前版本尚不支持凭“女孩抱着小狗”这类画面描述理解全电脑图片／视频；这是后续内容检索阶段。

## 阅读与其他功能

正文顶部“阅读”收纳复制、收藏、原文件、显示和跳转操作；Ctrl+Shift+R 切换专注阅读。文件名省略时可悬停查看完整路径。

0.3.1 阅读更新：第二列点击文件标题即可展开／折叠命中片段。蓝色引用可单击跳转；指向当前文件的引用直接打开源文件，Ctrl+单击任意引用也可打开源文件。引用上点右键可选择软件内查看、打开源文件、所在位置或复制路径。

侧栏保留搜索、资料库、收藏三个文字入口。底部菜单包含任务、工具、设置和帮助；开机启动与协议唤起在“设置 → 启动与唤起”。F1 的位置说明已更新，旧版详细功能说明继续保留。

本轮升级前程序保存在工作区“程序备份”目录，具体位置见发布记录。退出软件后再回退程序；资料库不属于本次程序替换范围。
