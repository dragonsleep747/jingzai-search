## 修复记录

| 问题 | 修订行为 |
|---|---|
| 无权限子目录或离线根目录仍可能触发旧记录清理 | 不完整扫描保留旧记录，标记 partial／offline 和补扫原因，离线结果明确标记 |
| Windows DirEntry.stat 身份信息可能为 0，文件身份混同、子目录误判循环 | Windows 元数据获取使用 lstat；没有可靠 ID 时不把 0 当成唯一身份 |
| 平铺目录整目录读完才写库，单目录缓存无界 | 条目循环内分批落库，验证单批上限 |
| 目录库及 WAL／SHM 可能被扫描或监听 | 按完整路径精确排除自身库和伴随文件，不误排其他同名资料 |
| 128 位 ID 无法可靠存入 INTEGER；批次写入反复加载全部对象 | 带前缀十六进制 TEXT 保存身份，兼容旧 64 位 ID；对象查询限定当前批次 |
| 目录更名遗漏直接子文件、删除不清子树、替换及扩展名更新不完整 | 修正路径边界、子树、目标替换与扩展名，均只处理目录记录 |
| 重复 USN 批次重复增加内容版本 | 事件去重；已提交同日志事件不二次应用 |
| 事件失败仍推进 checkpoint | 批次失败回滚，事件和游标同事务提交 |
| 未知／截断记录、缺路径和硬链接变更被跳过后仍报完成 | 保留游标并要求补扫，不冒充已消费 |
| 空块返回旧游标、跨块映射丢失、积压仍报完成 | 返回真实提交游标，跨块保留映射，读取量限流并区分剩余积压 |
| USN 枚举上界成为负数、续读使用最后一个文件 ID | 使用有符号正上界与缓冲区头部游标，EOF 作为枚举结束 |
| 观察回调直接写库、队列无实际限额、失败静默 | 观察线程入队、后台分批写；失效／溢出要求补扫，枚举前缓冲通知后回放 |
| 重扫与硬链接的内容缓存失效不完整 | 同一对象多路径共同失效；纯元数据变化区分；重扫检查版本变化 |
| 大小写、盘根边界、无扩展名与查询取消缺陷 | 修正字面匹配、Unicode 折叠、范围、扩展名和可取消查询 |
| 来源重复登记、挂载路径变化与覆盖数量失真 | 身份稳定、挂载变化要求补扫、数量按实际记录计算 |
| 长路径缺口 | IO 边界使用 Windows 扩展路径，展示保留原路径；真实超过 260 字符扫描通过 |
| demo／benchmark 会删除传入的现有目录或数据库 | 演示使用唯一子目录，已有目标库拒绝覆盖；实测保留哨兵文件 |
| URI 特殊字符、误传其他 SQLite 库 | URI 编码正确，拒绝迁移无关／较新库，验证原数据不变 |

## 实测与模拟的区别

- 真实样本验证：中文和特殊字符、多层目录、子树更名、硬链接、watchdog 更名／删除、超过 260 字符长路径、取消和错误恢复。
- 隔离 schema 1 → 2 迁移通过，旧负数 64 位 ID 保留对应无符号身份，未迁移原用户内容库。
- 独立进程 import 实验没有创建文件或启动线程。显式构造 Catalog／DiscoveryService 会初始化或迁移指定的目录库。
- F: 卷修正后真实枚举 1,000 条记录，本次有界快照解析出 992 条路径、8 条未解析路径；不代表完整枚举 F 盘。
- C:/D:/E: 当前权限下 USN 不可读，继续诚实回退。未提权、装服务或修改日志。
- 日志缺口、未知版本、跨块映射、回滚等使用模拟或合成记录验证。真实日志重建、卷拔插恢复未端到端验证。

十万条合成基准：写入约 5.09 秒，库 66.20 MiB，tracemalloc Python 分配峰值 11.5 MiB；名称首次查询约 22.21 ms，热查询平均 21.34 ms；首页 27.87 ms，offset=90000 约 122.99 ms；样本取消响应约 37.03 ms。

首次查询未清空 Windows 文件缓存，不是物理冷盘测试；tracemalloc 不代表整个进程工作集。合成基准不代表百万文件或真实全盘速度承诺。
